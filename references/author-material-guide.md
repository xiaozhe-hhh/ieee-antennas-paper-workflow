# 作者材料逐步交接指南

本指南用于科研论文全流程中需要作者人工补充文件、事实、实验或决策的场景。目标不是一次收齐所有材料，而是让作者每次提交一个可核验的小包，skill 随即完成对应工作并更新缺口。

## 一、交接原则

1. 先盘点已有材料，不要求作者重复提供。
2. 一次只推进当前阶段；优先索取会阻塞下一项结论的材料。
3. 每次请求分为 `现在必须`、`有则更好`、`投稿前必须`。
4. 说明材料用途、推荐格式、最低字段和验收标准。
5. 收到后先做完整性与一致性检查，再用于论文；不能读取、来源不明或条件缺失的结果不得写成事实。
6. 原始数据优先于截图，工程文件优先于手工抄录，官方模板优先于二手格式说明。
7. 缺失项写入 checkpoint 的 `evidence_gaps` 和 `author_checks`；不以合理猜测补齐。

## 二、推荐目录和命名

作者可以直接给出现有路径，不必为了符合本结构而移动原文件。新整理材料时建议使用：

```text
paper-project/
|-- 00_brief/          # 研究目标、投稿方向、作者信息
|-- 01_literature/     # PDF、检索结果、BibTeX
|-- 02_design/         # 结构、尺寸、理论推导、工程文件
|-- 03_simulation/     # 仿真工程、设置、导出数据
|-- 04_measurement/    # 测试设置、原始数据、照片、校准信息
|-- 05_figures/        # 可编辑源文件、原始数据、导出图
|-- 06_manuscript/     # Word/LaTeX、模板、参考文献
|-- 07_review/         # 审稿意见、逐条回复、修改记录
`-- 08_release/        # 最终 PDF、源文件和提交检查表
```

文件名应包含对象、条件和版本，例如 `S_parameters_measured_v2.csv`、`SAR_0p91GHz_20dBm_1g.csv`。不要覆盖原始文件；修订稿使用新版本号或日期。

## 三、分阶段提交

### 第 1 包：研究任务与边界

`现在必须`：一句话研究问题、研究对象、应用场景、目标期刊/会议、当前已有成果、希望本轮完成的具体输出。

`有则更好`：导师要求、时间节点、设备与软件限制、失败过的方法、旧稿或开题材料。

验收：能够写出可证伪的研究目标，并明确本轮不是在请求未知实验结果。

### 第 2 包：文献与现有工作

`现在必须`：已知最相关论文的 PDF 或 DOI/题名；尤其要提供被用作最近对比、理论依据或审稿人点名的原文。

`有则更好`：数据库导出的 BibTeX/RIS、检索式、检索日期、作者已做的批注。

`投稿前必须`：每条关键引文可追溯到原文页码、图、表或公式；元数据经过核验。

验收：PDF 可读取，论文身份明确，不能只用摘要或二手综述支持关键结论。

### 第 3 包：设计与机理

`现在必须`：结构图或工程文件、完整尺寸表、材料参数、坐标系、端口/馈电定义、工作频段与带宽判据、设计演化或基线。

`有则更好`：理论推导、等效电路、参数扫描、表面电流/场分布、失败设计。

验收：第三方能够理解几何、边界和比较对象；机理描述可由至少一种区分性证据检验。

### 第 4 包：仿真证据

`现在必须`：原始工程文件或可复算脚本、软件与求解器版本、网格/收敛条件、边界、端口、扫频设置、材料参数，以及导出的数值数据。

`有则更好`：不同网格或参数下的稳健性结果、计算资源与运行记录。

`投稿前必须`：正文中每条仿真数值都有对象、频率、单位、归一化和仿真条件；图片与导出数据一致。

验收：曲线不是仅有截图，设置足以判断可比性，仿真结果与测量结果有明确标签。

### 第 5 包：实验与测量证据

`现在必须`：样机照片、仪器型号、校准方法、连接与测试布置、测试距离/环境、原始测量文件、重复次数或不确定性说明。

`有则更好`：多台样机、重复测量、误差预算、空载/基线测试、实验视频或现场记录。

`投稿前必须`：所有报告数值都能回到原始记录；单位、参考面、归一化、样本数和异常处理明确。

验收：实验条件足以解释仿真与测量差异，且没有把单次截图包装成完整验证。

### 第 6 包：图表

`现在必须`：每幅图对应的原始数据或可编辑源文件、坐标与单位、图例含义、面板映射，以及希望证明的单一结论。

`投稿前必须`：最终导出图、源数据、正文引用和图注一致；缩至目标栏宽仍可读。

验收：图可复绘，不能从低分辨率截图反推精确数值。

### 第 7 包：稿件与投稿格式

`现在必须`：最新稿件、目标 venue、官方模板或官方链接、作者顺序与单位、已有 `.bib`、所有图表资产。

`有则更好`：cover letter、关键词偏好、既往版本和修改说明。

`投稿前必须`：作者确认题名、署名、基金、通信作者、利益冲突、数据可用性及其他声明；不得猜测卷期、版权号或收稿日期。

验收：本地 LaTeX 稳定编译，引用和图片无缺失，渲染 PDF 已目视检查。

### 第 8 包：审稿修改

`现在必须`：编辑决定信、完整审稿意见、被审版本、当前修订版本，以及作者能接受或不能接受的实验范围。

每条意见另外提供：相关论文原文、现有证据、准备补做的实验、可用仪器/工程文件、预计结果是否已经获得。

处理顺序：解释意见 -> 定位原稿 -> 核对文献 -> 定义所需证据 -> 作者补充/生成证据 -> 修改稿件 -> 起草回复 -> 事实复核。没有证据时，不先写成已经完成。

验收：每条意见有状态、稿件位置、证据路径和作者确认；除非用户要求，不自动创建回复信。

## 四、IEEE 天线与 SAR 专用材料

天线论文还应逐步补齐：

- 平台和天线尺寸、基板/导体参数、净空、馈电和匹配/去耦元件。
- 各端口工作频段、`|Sii|` 带宽门限、隔离度、效率、增益、方向图、ECC 等指标的定义与原始数据。
- 电流/电场图的激励端口、频率、相位、输入或接受功率、其他端口终端、色标与归一化。
- 多端口联合激励的幅度和相位向量，以及总功率还是每端口功率。
- SAR 的人体/体模模型、组织介电参数、天线距离与姿态、1-g/10-g 平均质量、输入或接受功率、活跃端口、非活跃端口终端、网格与求解设置。
- 实测 SAR 的系统、校准、扫描区域、液体参数、测量不确定度和原始报告。
- 与最近工作的公平对比字段：频段、单元数、尺寸/电尺寸、共享孔径、效率/增益、隔离、SAR 条件和测量状态。

如果只提供自由空间工程或归一化电流图，只能用于自由空间机理分析，不能据此宣称 SAR 合规或精确的多端口相位关系。

## 五、skill 向作者发出请求的固定格式

每轮最多发出一个主要材料包：

```text
当前阶段：<stage>
本轮要解决：<一个明确问题或结论>
现在请提供：
1. <材料及推荐格式>
2. <必须包含的字段/条件>
我会用它完成：<具体输出>
收到后先检查：<完整性、一致性、可追溯性>
暂时不用提供：<尚未进入的材料>
```

材料不完整但仍可推进时，先完成不依赖缺失证据的部分，并把缺口写成明确的作者动作；只有关键事实无法判断时才暂停该结论。
